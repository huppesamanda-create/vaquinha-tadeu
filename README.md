# Vaquinha do Tadeuzinho

Protótipo estático em HTML/CSS/JS.

## Como abrir
Abra `index.html` no navegador.

## Antes de publicar
1. Substitua `LINK_DA_VAQUINHA_OU_CHAVE_PIX` pelos dados oficiais.
2. Se já houver uma página oficial da vaquinha, você pode trocar o botão principal por um link externo.
3. Se quiser, adicione notas fiscais/recibos e atualizações do pós-operatório.

Todos os arquivos de imagem e vídeo estão na pasta `assets`.
